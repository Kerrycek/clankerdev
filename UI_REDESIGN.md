The current specification is the [design and requirements handbook](docs/design/README.md),
maintained in English in this repository.

## What happened to the old file?

Older documents and code comments referenced a sibling `UI_REDESIGN.md` outside
this repository. That original file was not found in the available workspace or
Clankerdev Git history checked on 2026-09-27. Its exact contents and numbered
sections cannot be recovered from those references alone.

This file is a navigation aid, **not a recovered copy of the original spec**.
The handbook replaces that missing dependency with documented requirements,
implementation evidence, decisions and explicit coverage limits. Historical
references do not establish that every former requirement has been reconstructed.
